# 南投國中綜合活動領域（輔導科）情緒調節課程 公開課評量分析與視覺化成果

本專案為 **南投縣立南投國民中學** 115 學年度綜合活動領域輔導科實習教師 **石伯華** 老師之「**情緒調節（SEL 社會情緒學習）**」公開授課／教學演示評量成果分析系統。

---

## 專案亮點與內容

- **網頁視覺化呈現**：具備響應式儀表板、Chart.js 四大動態圖表（等第佔比環狀圖、四大專業向度雷達圖、觀課師資身分佔比圖、14 項指標細項柱狀圖）。
- **密碼防護機制**：依規範設有安全驗證遮罩（存取密碼：`049`）。
- **互動檢索系統**：支援即時關鍵字過濾 13 位觀課教師評鑑卡片，點擊可開啟完整指標評分與質性評語對話框。
- **多元匯出功能**：支援一鍵下載 UTF-8 BOM CSV 統計報表，並內建列印／轉存 PDF 樣式最佳化。

---

- **單元名稱**：情緒調節（SEL）
